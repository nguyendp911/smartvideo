# VieLens
Máy ảnh iPhone với xử lý ảnh trên thiết bị và Timeline ngoại tuyến. Bundle ID của SmartVideo là `com.nguyendp911.smartvideo`. Tên ứng dụng mới là VieLens. Yêu cầu iOS 17 trở lên.

Mở máy ảnh và chụp. App đo phân bố sáng, tìm vùng mặt bằng Vision, điều chỉnh đường cong tông màu và lưu JPEG sRGB cùng bản gốc. Chạm khung ngắm để lấy nét, đổi ống kính hoặc đổi màu trong Tùy chọn. Camera đo chuyển động giữa các khung để cân bằng tốc độ và chất lượng. Hình trong khung ngắm là tín hiệu camera trực tiếp. Xử lý màu cuối diễn ra sau khi chụp.

Timeline lưu theo ngày, tháng và năm. Dùng trình đơn để nhập ảnh, so hai ảnh, sao lưu vào Tệp hoặc phục hồi. Bộ lọc tìm theo phiên, nhãn, ánh sáng hoặc ngày dạng YYYY-MM-DD. Mỗi ảnh có xếp hạng, file gốc, ảnh hoàn thiện, lưu sang Ảnh Apple và chia sẻ. Các ảnh đã xóa ở trong thùng rác tối đa 30 ngày. Để giữ dữ liệu trước khi gỡ app, chọn sao lưu vào một thư mục bên ngoài. Khi phục hồi, chọn thư mục VieLens chứa VieLens.json.

## Build
Trên Mac có Xcode và XcodeGen, chạy `xcodegen generate` rồi mở `VieLens.xcodeproj`. GitHub Actions trên main tạo IPA arm64 chưa ký và chạy các bài kiểm thử trên iOS Simulator. Artifact VieLens-iPhone-Unsigned chứa IPA và SHA-256. Ký lại bằng tài khoản của bạn trước khi cài lên iPhone.

## Masking Studio 16.3
Local per-photo mask stack: sky semantic Core ML (SkySegSmall 384×384, MIT model card, https://huggingface.co/twistlabs/fotometis-sky pinned 97dfe50bf3fe4dc02badea287512afaf4ce857c2), foreground/background via Vision, brush add/subtract, linear/radial gradients, luminance, inversion, threshold, feather and strength. Local exposure, contrast, HSL-like preset, warmth/tint, shadows/highlights, clarity, contrast-based haze control, sharpness. Mask overlay and undo for strokes/sliders. Rendering uses the same mask recipe for preview/export; source-specific masks are not copied to other shots or reusable presets. The small sky model is not Lightroom-class accuracy; buildings, branches and difficult clouds may need manual correction. No automatic sky replacement yet. `bash scripts/fetch-sky-model.sh` before local XcodeGen generation; CI downloads verified model and packages it for offline inference. Models are not committed as binary blobs. Original files unchanged.

Build 79: separate mask documents for each source image (UUID directory + source filename), optional imported sky image cropped to fill and composited strictly inside the sky mask. User-provided sky capped at 3000px, no automatic matching of reflections, shadows, or horizon. Source image is not overwritten. The sky replacement is saved inside the edit recipe; export is SDR.

## Personal Style AI 16.4
On-device Vision scene classification plus brightness-conditioned, weighted nearest-example preference learning. Records explicitly saved versions and a successful representative image per export batch; latest sample per photo, maximum 300 distinct photos. Global grade learns LUT/film voting and weighted settings; semantic region grades require two examples and regenerate masks on the new image after checking coverage. Never copies brush coordinates, replacements, crop/rotation or light textures into the taste profile. Suggestions require explicit Apply, preserve existing geometry and masks, and do not run if there are no same-scene examples. Optional manual scene override. Local protected profile can be disabled or reset, is not included in Life backup. No model-weight fine-tuning or online API calls. Unit tests cover deduplication, per-scene isolation, weighted learning, and mask transfer without brush data.

## Adaptive Skill Learning 16.5
Confirmed semantic-mask brush add/subtract strokes become labeled feature samples (base probability, RGB, local color/edge/position and neighborhood mask). A small regularized residual classifier is actually fitted locally, with independent profiles for sky/subject/background. Activate only after at least three images, both labels, and held-out-image correction-sample loss improves by 3%; this is not a whole-image accuracy benchmark. Store bounded samples (36 image-kind examples, max 128 points each) and learned weights, no copied images or stroke coordinates. New masks snapshot validated weights; compare with base AI, manually refine, opt out, or reset learning. Existing recipes retain snapshots for deterministic exports. Frozen Core ML/Vision model weights are unchanged. Training can fail to generalize; no accuracy guarantees. No network calls or API fees. Synthetic tests verify held-out correction improvement, isolation and brush precedence.

## Adaptive AI Core 17
Seven learnable semantic masks: sky, foreground, background, person segmentation, approximate face ellipse, eyes and lips from Vision landmarks. Corrections are learned separately per region using the existing held-out image validation, up to 12 source examples per kind. Adds local noise reduction and smoothing. Global workflow uses measured brightness, contrast, dark/highlight fractions, saturation, edge density and aspect ratio. Fits independent regularized residual regressors for eleven editing controls using confirmed distinct photo examples in the same scene/preset family; only enables when held-out mean absolute error against the user's settings improves by at least 5%, at least five examples. Recipe history includes crop ratio and reusable bundled light texture style (never imported texture bytes or placement). Workflow proposes these only with a majority across at least three samples, opt-in, plus regenerated validated semantic masks, undo. No model weight fine-tuning for Vision, no objective quality guarantee, no dedicated hair/skin/clothes/water/trees/buildings/roads/mountains/food/pet mask, no inpainting, restoration neural models or subject-aware crop yet. Models and learning remain local at runtime. Face ellipse is approximate, not face/skin parsing. Bundle ID unchanged.

Build 84: non-destructive crop position and Vision attention saliency. Learn offsets relative to saliency from confirmed crops, only reuse when held-out error improves by 5% over the base proposal, with at least three examples for the crop ratio. Only same-scene near samples; no learned raw absolute crop coordinates. No horizon correction yet.
